Этот скрипт лишь выкачивает бинарные файлы yarr, а затем делает из них установочные файлы для операционной системы OpenWRT. Автором yarr (yet another rss reader) является https://github.com/nkanaev, а это лишь скрипт, который позволяет сделать ipk файлы для установки yarr на OpenWRT через системные пакеты.
https://github.com/nkanaev/yarr

Приложение находится на этапе разработки. Работать то работает, но пока так. Если будет время, то дополирую код. Однако, даже в таком виде приложение можно ставить быстро поставить на OpenWrt и пользоваться.

Конечно, переход на нормальную сборку из исходников и по гайдлайнам OpenWrt в планах, как и задействование Actions GitHub, но это позже. Пока мне удобнее действовать через самосборный sh скрипт.
